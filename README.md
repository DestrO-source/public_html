# WordPress Internship Website

This repository contains the WordPress website created during my MICTSETA internship and hosted on Hostinger.

## Project context

Creating this website was an individual task assigned to us interns.

## Repository contents

The repository contains the WordPress site files from the `public_html` directory, including its installed themes, plugins, and media. WordPress page, product, and settings data is stored in the site's database, which is not included here. A database export is needed to reproduce the complete site.

## Local setup

1. Copy the files to a PHP-enabled web server with a MySQL-compatible database.
2. Create a database and configure local connection details in `wp-config.php`. Do not commit credentials or authentication keys.
3. Import a matching WordPress database backup if one is available.

The live database and hosting credentials are not part of this repository.
